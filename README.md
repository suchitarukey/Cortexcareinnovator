Value Based Care Command Center powered by Snowflake Cortex
📌 Project Overview

Cortexcareinnovator is an AI-powered healthcare analytics application built to support value-based care decision-making.

It brings together fragmented healthcare data into a single intelligent command center that helps organizations:

💸 Recover lost revenue

🚑 Reduce avoidable healthcare costs

🩺 Improve quality of care

The platform leverages Snowflake Cortex AI to generate insights, automate analysis, and enable real-time decision support — without complex ML pipelines.

🎯 Problem Statement

Healthcare systems struggle with:

Missed HCC recapture → Revenue leakage

High ER utilization → Avoidable costs

Low preventive screening compliance → Poor quality scores

Slow, manual analytics → Delayed decisions

💡 Solution

The Value Based Care Command Center solves these challenges by:

✔ Providing real-time KPI dashboards
✔ Enabling AI-powered insights using Cortex
✔ Offering guided Q&A for business users
✔ Delivering actionable recommendations instantly

🚀 Key Features
💰 HCC Recapture (Revenue Optimization)

Track recapture rates

Identify missed diagnoses

Calculate revenue leakage (~$3000 per HCC)

Provider-level performance insights

🚑 ER Utilization (Cost Reduction)

Identify non-urgent ER visits

Measure avoidable costs

Detect frequent utilizers

Target high-cost drivers

🩺 Preventive Screening (Quality Improvement)

Monitor screening compliance (~60%)

Identify missed opportunities (~40%)

Highlight provider variation

Improve Star Ratings

🤖 AI-Powered Insights (Cortex)

One-click “Generate Insights”

Natural language Q&A

Instant, data-backed answers

Actionable recommendations

🛠️ Technologies Used

Programming Language: Python

⚙️ How to Run

Clone the repository:

git clone https://github.com/suchitarukey/Cortexcareinnovator.git


Navigate to the project folder:

cd Cortexcareinnovator


Install dependencies:

pip install -r requirements.txt


Run the Streamlit app:

streamlit run app.py
